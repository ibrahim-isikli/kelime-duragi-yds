# Kelime Durağı: YDS Kelime

YDS kelime kartları, test, gramer ve sözlük. Telefona "Ana ekrana ekle" ile kurulur, internetsiz çalışır.

- Kaynak: `kaynak/kelime-duragi-yds.html` (uygulamanın tamamı: veri, yazı tipleri ve kod).
- Yayın: `python3 build.py` → `index.html` ve `sw.js` üretilir.
- `manifest.webmanifest` kurulum bilgisi, `icons/` uygulama simgeleri.

ÖSYM ile bağlantısı yoktur. Örnek cümleler yapay zekâ yardımıyla üretilmiştir.
